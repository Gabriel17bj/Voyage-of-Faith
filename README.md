# 믿음의 항해

성경 말씀 36개를 외우며 바다를 건너는 모바일 웹 게임입니다.
학생은 **이름 + 수업 코드**만 넣으면 참여하고, 기록은 선생님의 **구글 스프레드시트**에 쌓입니다.

- 학생 화면: `https://프로젝트이름.vercel.app`
- 선생님 화면: `https://프로젝트이름.vercel.app/#/teacher`
- 기록 시트: https://docs.google.com/spreadsheets/d/1aHq_nl4P0pMWBKHdSI_S_BOoFdVs7dZhk03npbWadBc/edit

## 구글 시트 연결 (처음 한 번, 약 5분)

게임의 **선생님 화면**을 열면 아래 순서가 그대로 나오고, 코드 복사 버튼과 주소 입력 칸이 있습니다.

1. **시트에 코드 붙여넣기**
   기록 시트 → 위쪽 메뉴 **확장 프로그램 → Apps Script** → 원래 내용을 지우고 `gas/Code.gs` 내용을 붙여넣고 저장(💾)
2. **웹 앱으로 배포하기**
   Apps Script 오른쪽 위 **배포 → 새 배포 → ⚙️ → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 권한 승인 화면: 계정 선택 → 고급 → 이동 → 허용
3. **웹 앱 주소 붙여넣기**
   배포 마지막 화면의 웹 앱 URL(`…/exec`)을 선생님 화면의 입력 칸에 붙여넣고 **연결하기**
   (시트 메뉴 **[믿음의 항해 → 게임과 연결하기]** 에서도 주소를 다시 볼 수 있어요)

그다음 시트를 새로고침하면 생기는 **[믿음의 항해]** 메뉴에서
- **교사 비밀번호 정하기** → 선생님 화면 로그인
- **새 수업 만들기** → 학생에게 알려 줄 5자리 수업 코드 (`수업` 탭에 직접 적어도 됨)

### 학생이 코드만 입력해도 연결되게 하기 (권장)
3번까지만 하면 선생님이 보낸 **초대 링크**로 들어온 학생이 연결됩니다.
링크 없이 **이름 + 코드만** 입력해도 되게 하려면 웹 앱 주소를 `src/config.ts` 에 넣어 주세요.

```ts
export const GAS_WEB_APP_URL = 'https://script.google.com/macros/s/…/exec';
```

GitHub에서 이 파일을 고쳐 저장하면 Vercel이 자동으로 다시 배포합니다.

## 시트 구성 (자동 생성)

| 탭 | 내용 |
| --- | --- |
| `수업` | 수업 코드, 수업명, 입장 마감 여부 |
| `학생현황` | 학생 한 명당 한 줄: 점수·푼 말씀·별·힌트·틀린 횟수·접속 여부·마지막 활동 |
| `게임기록` | 완주/중간 종료 결과가 한 줄씩 추가 (게임에서 지울 수 없음) |

시트의 탭 이름과 열 순서는 바꾸지 마세요. `gas/Code.gs`를 고쳤다면 Apps Script에서 **배포 → 배포 관리 → ✏️ → 새 버전**으로 다시 배포합니다(주소는 그대로).

## 화면

| 학생 | 선생님 |
| --- | --- |
| 시작(선장 이름·수업 코드) → 항해 지도(36개 지점) → 말씀 풀기 → 단계 성공 → 약속의 땅 도착 | 로그인 → 수업 목록 → 수업(현황 / 기록 / 관리) |

말씀 풀기는 1단계 빈칸 채우기 · 2단계 순서 맞추기 · 3단계 빈칸 여러 개 · 4단계 따라 쓰기 · 5단계 외워 쓰기입니다. 힌트 버튼 1개, 세 번 틀리면 정답 보기.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| 선생님 화면에 "구글 시트 연결하기" 안내가 나옴 | 위 1~3단계를 진행 |
| "교사 비밀번호가 없습니다" | 시트 메뉴 **[믿음의 항해 → 교사 비밀번호 정하기]** |
| "구글 시트에 연결할 수 없어요" | 웹 앱 액세스 권한을 **모든 사용자**로 다시 배포 |
| 학생: "아직 선생님이 구글 시트를 연결하지 않았어요" | 선생님이 보낸 초대 링크로 들어오기, 또는 `src/config.ts`에 주소 넣기 |
| 학생: "수업 코드를 찾을 수 없습니다" | 시트 `수업` 탭에 있는 코드인지 확인 (0과 O, 1과 I 구분) |

## 개발

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # dist/ (Vercel이 자동으로 실행)
```
