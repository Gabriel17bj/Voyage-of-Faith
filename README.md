# PROMISE LAND : 믿음의 항해

예수님과 함께하는 36개 성경 말씀 암송 모바일 RPG 웹 게임.
학생은 **수업 코드(5자리)** 로 입장하고, 교사는 **교사 대시보드**에서 전체 학생의 실시간 현황과 게임 기록을 확인합니다.

## 주요 기능

| 구분 | 내용 |
| --- | --- |
| 모바일 최적화 | 세로 화면: 지도 아래 조작 패널(조이스틱·힌트·A/B 버튼) / 가로 화면: 좌우 조작 패널 / PC: 16:9 화면. 노치·홈바(safe-area), iOS 입력창 확대 방지, 홈 화면 추가(웹앱) 지원 |
| 수업 코드 | 교사가 5자리 코드를 만들고 `https://사이트주소/?code=ABCDE` 링크나 코드를 학생에게 전달 |
| 실시간 현황 | 접속/오프라인 상태, 현재 점수·푼 말씀 수·별·힌트·오답, 도움이 필요한 학생, 말씀별 오답 통계, 프로젝터(빔) 모드 |
| 게임 기록 | 학생이 **완주**하거나 설정에서 **초기화(중도 종료)** 하면 결과가 자동 저장. 학생 현황을 초기화해도 기록은 남고, CSV(엑셀)로 저장 가능 |

교사 대시보드 주소: `https://사이트주소/#/teacher`

## 기록 저장 방식 (자동 선택)

1. **구글 스프레드시트 모드 (권장)** — 구글 시트 + Apps Script 웹 앱. 학생 현황과 게임 기록이 시트에 바로 쌓여 교사가 언제든 열어볼 수 있습니다. 교사 화면은 약 5초마다 새로고침됩니다.
2. **Firebase 모드** — Firestore 사용(설정 시). 즉시 실시간 반영.
3. **서버 모드** — AI Studio 미리보기 / `npm run dev` 에서 `server.ts`가 동작할 때.
4. **로컬 모드** — 위 설정이 하나도 없을 때. 같은 브라우저 안에서만 동작(체험용). 다른 휴대폰은 접속할 수 없고 교사 대시보드에 빨간 경고가 뜹니다.

> ⚠️ Vercel은 `server.ts`(Express 서버)를 실행하지 않습니다. Vercel에 배포해서 여러 학생을 모니터링하려면 구글 스프레드시트(또는 Firebase)를 연결해야 합니다.

## 구글 스프레드시트(GAS) 연결 (약 5분)

### 1) 스프레드시트와 Apps Script 만들기
1. https://sheets.new 에서 새 스프레드시트를 만들고 이름을 정합니다. (예: `믿음의 항해 기록`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 저장소의 **`gas/Code.gs`** 내용을 전부 붙여넣은 뒤 💾 저장합니다.

### 2) 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → ⚙️(유형 선택) → **웹 앱**
2. 설정
   - 설명: `믿음의 항해 기록 서버`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 꼭 이것으로 (학생이 로그인 없이 기록해야 함)
3. **배포** → 권한 승인(구글 계정 선택 → "고급" → "안전하지 않은 페이지로 이동" → 허용)
4. 나타나는 **웹 앱 URL** (`https://script.google.com/macros/s/……/exec`)을 복사합니다.

### 3) 게임에 주소 넣기 (둘 중 하나)
- **방법 A (간단):** `src/config.ts` 의 `GAS_WEB_APP_URL = ''` 따옴표 안에 주소를 붙여넣고 GitHub에 저장 → Vercel이 자동 재배포
- **방법 B:** Vercel **Settings → Environment Variables** 에 `VITE_GAS_URL` = 주소 등록 → **Redeploy**

### 4) 확인
`https://프로젝트이름.vercel.app/#/teacher` 상단 배지가 **"구글 시트 연동"** 이면 성공입니다.
대시보드에서 [+]로 수업을 만들면 시트의 `수업` 탭에 줄이 생기고, 초대 버튼의 **📡 접속 진단**이 모두 ✅ 이면 학생이 접속할 수 있습니다.

### 시트 구성 (자동 생성)
| 탭 | 내용 |
| --- | --- |
| `수업` | 교사가 만든 수업 코드, 수업명, 입장 마감 여부 |
| `학생현황` | 학생 한 명당 한 줄. 점수·푼 말씀·별·힌트·오답·접속 여부·마지막 활동 시각이 계속 갱신 |
| `게임기록` | 완주/중도 종료 결과가 한 줄씩 **추가만** 됨 (앱에서 삭제 불가 → 영구 기록). 시트에서 정렬·필터·차트 자유롭게 사용 |

### 알아두기
- **`gas/Code.gs`를 수정했다면** Apps Script에서 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (주소는 그대로 유지)
- 개인 Gmail 계정의 Apps Script는 동시에 처리할 수 있는 요청 수에 한도가 있습니다. 한 수업 **30~40명** 정도까지 권장하며, 학생 기기는 60초마다 접속 신호를 보내도록 조정되어 있습니다. 교회/학교 Google Workspace 계정이면 더 여유롭습니다.
- 시트의 열 순서·탭 이름을 바꾸지 마세요. (열 추가가 필요하면 맨 오른쪽 바깥에 추가)

## Firebase 설정 (선택, 스프레드시트 대신 사용할 때)

1. https://console.firebase.google.com 에서 프로젝트 생성
2. **빌드 > Firestore Database > 데이터베이스 만들기** (위치: `asia-northeast3 (서울)` 권장)
3. **Firestore > 규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 **게시**
4. **프로젝트 설정(⚙️) > 일반 > 내 앱 > 웹 앱 추가(</>)** 후 표시되는 `firebaseConfig` 값 확인
5. 아래 환경변수를 등록 (API 키는 구글 API 키 `AIza...` 를 그대로 사용)

| 환경변수 | firebaseConfig 항목 | 필수 |
| --- | --- | --- |
| `VITE_FIREBASE_API_KEY` | `apiKey` | ✅ |
| `VITE_FIREBASE_PROJECT_ID` | `projectId` | ✅ |
| `VITE_FIREBASE_AUTH_DOMAIN` | `authDomain` | 선택 |
| `VITE_FIREBASE_APP_ID` | `appId` | 선택 |
| `VITE_FIREBASE_DATABASE_ID` | (기본 DB가 아닐 때만) | 선택 |
| `VITE_PUBLIC_APP_URL` | 학생 초대 링크에 쓸 공개 주소 (예: `https://voyage-of-faith.vercel.app`) | 선택 |

Google AI Studio에서 Firebase를 연결해 `firebase-applet-config.json` 파일이 생긴 경우, 환경변수가 없어도 그 파일 값을 자동으로 사용합니다.

## Vercel 배포

1. GitHub 저장소를 Vercel에서 **Import**
2. Framework: **Vite** (자동 인식, `vercel.json` 포함)
3. 구글 스프레드시트를 쓰면 `src/config.ts`에 주소를 넣었는지 확인 (또는 **Settings > Environment Variables** 에 `VITE_GAS_URL` 등록). Firebase를 쓰면 `VITE_FIREBASE_*` 등록. `GEMINI_API_KEY`도 기존처럼 등록 가능
4. **Deploy** — 환경변수를 바꾼 뒤에는 반드시 **Redeploy** 해야 반영됩니다(빌드 시 포함되는 값).

배포 후 확인: `/#/teacher` 상단 배지가 **"구글 시트 연동"**(또는 Firebase면 **"클라우드 실시간"**) 이면 연결 성공입니다.

## 다른 휴대폰에서 접속이 안 될 때

교사 대시보드 → **초대(공유) 버튼** 또는 **수업 관리** 탭의 **📡 다른 기기 접속 진단**을 누르면 원인을 바로 알려줍니다.

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 대시보드 상단에 빨간 **로컬 모드** 경고 / 학생 화면에 "기록 서버(구글 스프레드시트)가 설정되어 있지 않아…" | 스프레드시트 웹 앱 주소(또는 Firebase)가 배포에 없음 (Vercel은 server.ts를 실행하지 않음) | `src/config.ts`에 주소 입력 또는 `VITE_GAS_URL` 등록 → 재배포 |
| "구글 스프레드시트 서버에 연결할 수 없습니다" / "올바른 응답을 주지 않았습니다" | 웹 앱 액세스 권한이 "모든 사용자"가 아니거나 주소가 `/exec`로 끝나지 않음 | Apps Script 배포 관리에서 액세스 권한 "모든 사용자"로 새 버전 배포 |
| "수업 코드 [XXXXX]를 찾을 수 없습니다" | 코드 오타이거나, 교사가 만든 수업이 아님 | 대시보드에서 [+]로 수업을 만들고 그 코드를 사용 |
| "접근을 거부했습니다" | Firestore 규칙 미게시 | `firestore.rules` 내용을 Firestore 규칙에 붙여넣고 게시 |
| "응답이 없습니다" | Firestore 데이터베이스 미생성 / 프로젝트 ID 오타 / 네트워크 | Firestore Database 만들기, 환경변수 확인 |
| "API 키가 올바르지 않습니다" / "Cloud Firestore API가 꺼져 있습니다" | Gemini용 키 등 다른 프로젝트의 키를 넣음 | Firebase 콘솔 웹 앱 설정의 `apiKey`를 그대로 사용 |
| 링크를 눌러도 페이지가 안 열림 / 로그인 화면이 나옴 | AI Studio 미리보기 주소나 Vercel **미리보기(Preview)** 주소를 공유함 | `https://프로젝트이름.vercel.app` (Production) 주소에서 대시보드를 열고 링크 복사. 또는 `VITE_PUBLIC_APP_URL` 환경변수에 공개 주소 지정 |

## 로컬 실행

```bash
npm install
npm run dev   # http://localhost:3000 (server.ts + Vite)
```

## 보안 참고

- 학생은 로그인 없이 참여하므로 Firestore 규칙은 인증 대신 데이터 형식/점수 범위를 검증합니다.
- 교사 대시보드 주소(`/#/teacher`)는 학생에게 공유하지 마세요.
- 구글 스프레드시트 모드: 웹 앱 주소를 아는 사람은 기록을 추가할 수 있지만, `게임기록` 탭은 앱에서 지울 수 없습니다. 스프레드시트 자체는 교사 본인 계정에만 공유되어 있습니다(공유 설정을 바꾸지 마세요).
